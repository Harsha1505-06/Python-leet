## 🚀 LeetCode → GitHub

The intended workflow is:

```text
Solve on LeetCode
      ↓
Submit
      ↓
Accepted
      ↓
LeetHub / LeetCode sync
      ↓
Python-leet repository
```

LeetHub is a browser-based sync tool. After it is connected to this repository, accepted solutions can be pushed automatically.
